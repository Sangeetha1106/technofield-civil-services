# Technofield Civil Services Private Limited - Official Website

Specialised construction protection, structural rehabilitation, and high-performance industrial flooring solutions.

## Overview
Technofield Civil Services Private Limited delivers engineering-backed civil protection services including:
- **Waterproofing Solutions:** Terrace, basement, balcony, wet area, and underground sump waterproofing.
- **Epoxy Tile Grouting:** Specialised joint-filling applications for commercial and industrial facilities.
- **Structural Repairs & Retrofitting:** Crack injection, expansion joint treatment, and concrete rehabilitation.
- **Protective Coatings:** Anti-carbonation, anti-corrosion, and anti-bacterial coating systems.
- **Industrial Flooring:** Heavy-duty epoxy and polyurethane flooring systems for warehouses, car parks, and manufacturing plants.

## Running Locally
Simply open `index.html` in any modern web browser or serve via a local HTTP server:
```bash
# Using Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
